What’s inside

everything you can do with it

Not a feature dump, a toolbox. Here is what you, the person at the board, can actually do once the app is open.

Build your stage

Compose scenes

Build as many scenes as you need, each with its own layout, background color and set of sources, then hop between them live.

Drag, resize, layer

Move and scale any source right on the canvas, rotate it, flip it, set its opacity, reorder the stack, or lock it in place when it is perfect.

Switch with style

Cut instantly or glide between scenes with Fade, Move and Stinger transitions, each with its own speed and easing.

Undo, redo, relax

Every layout change is tracked, so you can step back and forth through your edits until the board looks right.

Snap and center

Turn on snap to grid for tidy layouts, center a source in one tap, or blow it up to fullscreen and restore it just as fast.

Your own hotkeys

Bind keys to scenes and everyday actions like centering, locking and hiding, then run the whole show from the keyboard.

Bring in your media

Fourteen source types

Text, images, video, camera, screen capture, web pages, color blocks, galleries, code, paint, a visualizer, emoji, YouTube and Twitch. The full panel is chalked up below.

Go live on the canvas

Drop in your webcam or share your screen as a source, side by side with everything else in the scene.

Paint on top of it all

The Paint source is a whiteboard layer that sits over your scene, with your choice of brush size and color, for annotating live.

Run your own code

Code sources render your HTML, CSS and JavaScript in an isolated widget, so you can build particles, tickers and effects right on the canvas. The demo ships with a Matrix rain to prove it.

Stream players built in

YouTube and Twitch sources play inside your scene, with playlist support on YouTube and video plus chat layouts on Twitch.

Galleries that cycle

Load a set of images into a Gallery source and let it rotate through them on a timer you set.

Make it yours, keep it safe

Key out the background

Chroma key and color key controls with sensitivity sliders let you lift a subject off a solid backdrop, green screen style.

Filters and shapes

Shift the hue, add blur or sharpness, and mask a source into a circle, oval, triangle, diamond, star or hexagon.

Nine themes

Restyle the whole studio in one pick: Light, Dark, Crimson, Metallic, Lime, Purple, Lemon, Silverado or Orange.

Canvas up to 4K

Set your canvas resolution from 240p all the way to 4K, and preview it fit to screen or at true size.

Save and share projects

Export a whole project, a scene’s sources, your settings, or a full master backup to a file, then import it back on any machine.

Keep it smooth

Performance presets, a frame rate limit and a render scale dial let you trade a little sparkle for a lot of smoothness on modest hardware.

Get started in five steps

no install, no setup wizard
1

Open the app

Hit Open Creative Canvas. It loads in your browser, and the welcome board walks you through the studio.

2

Pick a scene

Start from a demo scene to see how layouts work, or add your own and name it whatever the show is called.

3

Add sources

Choose from the fourteen source types and drop in your media, camera, web pages, code and text.

4

Arrange the board

Drag everything into place, layer it, key out backgrounds, and set how scenes transition into each other.

5

Perform, then save

Hide the interface for a clean fullscreen canvas, and export your project file so the whole setup travels with you.

Chalkboard tips

Straight from the app’s own performance guide, for a buttery smooth board.

Lower the frame rate

A busy canvas works hard. Dropping the target FPS in the Canvas panel trims idle CPU use and keeps everything responsive.

Hide what you are not using

Hidden or locked static sources skip the heavy drawing work, so tuck away anything the current scene does not need.

Throttle busy code

Code sources run real JavaScript. If a widget loops hard on a timer, slow the loop down and the whole canvas breathes easier.

Use performance mode

Hide the interface with the toggle in the corner and the canvas takes the full screen, clean and ready to present or record.

Questions

The ones everybody asks at the board.

Do I need to install anything?

No. Creative Canvas runs entirely in the browser. Open the page, and the studio is ready, on desktop or mobile.

Is it like OBS?

It borrows the parts of OBS people love, scenes made of layered sources that you switch between live, and rebuilds them for the web. There is no streaming encoder inside the app itself, so most people present with it, record their screen, or feed the fullscreen canvas into their tool of choice.

Where do my projects live?

In files you control. Export a project, a scene’s sources, your settings, or a complete master backup, and import the file whenever and wherever you want to pick the work back up.

Can I really put code on the canvas?

Yes. A Code source takes your HTML, CSS and JavaScript and renders it live in its own isolated frame. The Code Example demo scene ships with a Matrix rain and a falling snow effect written exactly that way.
